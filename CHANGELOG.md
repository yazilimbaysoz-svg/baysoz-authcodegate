## 1.0.0 — 2026-11-26

- Initial production release by Baysöz Labs <baysozlabs@proton.me>.
- Strict typed evidence model for authorization requests, token exchanges, clients, policies and code registries.
- 26-rule OAuth 2.1 / OIDC authorization-code catalogue with RFC references.
- PKCE S256 verification, plain-method downgrade rejection and canonical base64url parsing.
- Exact redirect-URI matching, scheme safety, scope containment, state/nonce checks and duplicate-parameter detection.
- RFC 8707 resource-indicator audience binding and RFC 9700 issuer-mix-up detection.
- Stateful single-use detection for authorization codes and DPoP proof identifiers.
- RFC 9449 DPoP verification for EdDSA/ES256 with embedded JWK, nonce and endpoint binding.
- Deterministic 44-case adversarial corpus with real signed proofs and six-juror Supreme Grand Jury Tribunal.
- SARIF 2.1.0 output with stable finding fingerprints and CI exit codes.
- `audit`, `forge`, `selftest`, `tribunal` and `rules` CLI commands with Baysöz Labs attribution.
